# 🚛 Vehicle Request and Approval System

A centralized web-based system for the **Ethiopian Pharmaceutical Supply Service (EPSS)** to manage vehicle requests, approvals, and driver assignments.

## 🔄 Workflow

**Requester → Approver → Assignment & Logistics**

1. **Requester** submits a vehicle request.
2. **Approver** reviews and approves or rejects.
3. **Logistics** assigns a driver and plate number.

## 🛠️ Tech Stack

- Frontend: Streamlit
- Language: Python
- Database: SQLite (dev) → PostgreSQL/Supabase (prod)
- Hosting: Streamlit Community Cloud
- Code: GitHub
